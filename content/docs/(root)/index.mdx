**transition-kit** provides beautiful UI transitions for React. Built on React 19.3's [`<ViewTransition>`](https://react.dev/reference/react/ViewTransition), `startTransition` and `addTransitionType`, and designed to work seamlessly with the [shadcn CLI](https://ui.shadcn.com).

## Philosophy

transition-kit follows the shadcn model for motion: copy-paste code you own, with zero lock-in and defaults that work immediately.

View transitions are often wired up by hand — `document.startViewTransition` calls scattered across event handlers, racing the framework's own rendering. transition-kit takes a different approach. **React owns the transition**: every state change runs inside `startTransition`, tagged with `addTransitionType`, and React decides what to snapshot and when. There is no animation library and no runtime beyond React itself.

Each transition is a few lines of plain CSS or a copy-paste component. The shadcn CLI adds it to your project, where you can tweak timing, easing and keyframes like any other stylesheet.

## What's inside

Browse [Components](/docs/components) to find your transition — animated theme toggles, page transitions and interactive components (tabs, carousel, kanban board and more). Installing any of them pulls in its core automatically.
