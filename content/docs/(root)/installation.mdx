## Prerequisites

transition-kit needs **React 19.3** or later for `<ViewTransition>` and `addTransitionType`.

```bash
npm install react@19.3 react-dom@19.3
```

In browsers without the View Transitions API, React applies every update instantly with no errors. With `prefers-reduced-motion`, nothing travels. Page transitions only animate when their `id` changes inside a React Transition.

## Setup

Skip this if your project already has a `components.json`.

```bash
npx shadcn@latest init
```

```json title="components.json"
{
  "registries": {
    "@transition-kit": "https://transition-kit.space/r/{name}.json"
  }
}
```
