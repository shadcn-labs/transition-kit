## Usage

```tsx
import {
  ToastProvider,
  ToastViewport,
  useToast,
} from "@/components/transitions/toast-stack";
```

```tsx
<ToastProvider>
  <App />
  <ToastViewport className="fixed right-4 bottom-4 z-50" />
</ToastProvider>
```

```tsx
const { toast, dismiss } = useToast();

const id = toast({
  title: "Deploy finished",
  description: "Production is live at v2.14.0.",
});
dismiss(id); // one toast
dismiss(); // all toasts
```

Toasts dismiss themselves after `duration`. Hovering or focusing the stack pauses the timers.

## API Reference

### ToastProvider

| Prop       | Type     | Default | Description                                           |
| ---------- | -------- | ------- | ----------------------------------------------------- |
| `limit`    | `number` | `3`     | Most toasts on screen. The oldest leaves first.       |
| `duration` | `number` | `4000`  | Default milliseconds before a toast dismisses itself. |

### toast(options)

| Option        | Type        | Default    | Description                                    |
| ------------- | ----------- | ---------- | ---------------------------------------------- |
| `title`       | `ReactNode` | -          | Toast heading.                                 |
| `description` | `ReactNode` | -          | Secondary text.                                |
| `action`      | `ReactNode` | -          | An extra control, e.g. an Undo button.         |
| `duration`    | `number`    | provider's | Milliseconds before closing. `Infinity` stays. |

Returns the toast's `id`.
