## Usage

```tsx
import {
  StackNavigator,
  StackScreen,
  useStack,
} from "@/components/transitions/stack-navigator";
```

```tsx
const Inbox = () => {
  const { push } = useStack();
  return (
    <button type="button" onClick={() => push("chat", { id: "ava" })}>
      Ava Chen
    </button>
  );
};

<StackNavigator initialScreen="inbox" className="h-96 max-w-sm">
  <StackScreen name="inbox" title="Messages" render={() => <Inbox />} />
  <StackScreen<{ id: string }>
    name="chat"
    title={({ id }) => getChat(id).name}
    actions={({ id }) => <ContactButton id={id} />}
    render={({ id }) => <Conversation id={id} />}
  />
</StackNavigator>;
```

## API Reference

### StackNavigator

| Prop            | Type                            | Default             | Description                                       |
| --------------- | ------------------------------- | ------------------- | ------------------------------------------------- |
| `initialScreen` | `string`                        | first `StackScreen` | Uncontrolled root screen.                         |
| `initialParams` | `Record<string, unknown>`       | `{}`                | Params for the uncontrolled root entry.           |
| `stack`         | `StackEntry[]`                  | -                   | Controlled stack, root first.                     |
| `onStackChange` | `(stack: StackEntry[]) => void` | -                   | Called with the next stack after each navigation. |

### StackScreen

| Prop      | Type                                 | Default | Description                                                               |
| --------- | ------------------------------------ | ------- | ------------------------------------------------------------------------- |
| `name`    | `string`                             | -       | Unique screen name referenced by `initialScreen` and `push`.              |
| `render`  | `(params) => ReactNode`              | -       | Screen content rendered for the entry's params.                           |
| `title`   | `ReactNode \| (params) => ReactNode` | -       | Header title; morphs into the back button when a screen is pushed on top. |
| `actions` | `ReactNode \| (params) => ReactNode` | -       | Trailing header content, e.g. an icon button.                             |

### useStack

| Return      | Type                                                         | Description                              |
| ----------- | ------------------------------------------------------------ | ---------------------------------------- |
| `push`      | `(screen: string, params?: Record<string, unknown>) => void` | Pushes a new entry onto the stack.       |
| `pop`       | `() => void`                                                 | Goes back one screen; no-op at the root. |
| `popToRoot` | `() => void`                                                 | Pops back to the root entry.             |
| `stack`     | `StackEntry[]`                                               | Current stack, root first.               |

## Accessibility

- The back button is a real `<button>` named "Back to _previous title_" when the title is text.
- <kbd>Esc</kbd> anywhere inside the navigator goes back one screen.
- Pushing moves focus to the new screen, which is labelled by the header title. Popping returns focus to the control that opened the screen.
- Hidden lower screens use `visibility: hidden`, so they are skipped by the keyboard and screen readers.
- With `prefers-reduced-motion`, nothing slides; screens and titles crossfade briefly.
