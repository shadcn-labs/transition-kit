## Usage

```tsx
import { TextMorph } from "@/components/transitions/text-morph";
```

```tsx
<TextMorph>{copied ? "Copied!" : "Copy link"}</TextMorph>
```

Change the text with a plain `setState`; `TextMorph` starts the transition itself. Letters are matched by character and occurrence, so the `t`s in "transition" and "station" glide to their new spots while the others fade.

## API Reference

### TextMorph

| Prop       | Type     | Default | Description                                                    |
| ---------- | -------- | ------- | -------------------------------------------------------------- |
| `children` | `string` | -       | The text to show. Each change morphs from the previous string. |

Screen readers get the full string; the animated letters are hidden from them.
