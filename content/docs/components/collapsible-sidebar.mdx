## Usage

```tsx
import {
  CollapsibleSidebar,
  CollapsibleSidebarInset,
  CollapsibleSidebarItem,
  CollapsibleSidebarProvider,
  CollapsibleSidebarTrigger,
} from "@/components/transitions/collapsible-sidebar";
```

```tsx
<CollapsibleSidebarProvider defaultValue="home">
  <CollapsibleSidebar aria-label="Main">
    <CollapsibleSidebarTrigger />
    <CollapsibleSidebarItem value="home" icon={<HouseIcon />}>
      Home
    </CollapsibleSidebarItem>
    <CollapsibleSidebarItem value="inbox" icon={<InboxIcon />}>
      Inbox
    </CollapsibleSidebarItem>
  </CollapsibleSidebar>
  <CollapsibleSidebarInset>{/* page content */}</CollapsibleSidebarInset>
</CollapsibleSidebarProvider>
```

`useCollapsibleSidebar()` returns `{ collapsed, setCollapsed, value, select }` inside the provider.

## API Reference

### CollapsibleSidebarProvider

| Prop                | Type                           | Default | Description                                   |
| ------------------- | ------------------------------ | ------- | --------------------------------------------- |
| `collapsed`         | `boolean`                      | -       | Controlled collapsed state.                   |
| `defaultCollapsed`  | `boolean`                      | `false` | Initial collapsed state when uncontrolled.    |
| `onCollapsedChange` | `(collapsed: boolean) => void` | -       | Called when the sidebar collapses or expands. |
| `value`             | `string`                       | -       | Controlled active item.                       |
| `defaultValue`      | `string`                       | `""`    | Initial active item when uncontrolled.        |
| `onValueChange`     | `(value: string) => void`      | -       | Called when another item is chosen.           |

### CollapsibleSidebarItem

| Prop    | Type        | Default | Description           |
| ------- | ----------- | ------- | --------------------- |
| `value` | `string`    | -       | Identifies the item.  |
| `icon`  | `ReactNode` | -       | Shown in both states. |

Change the corner radius with `:root { --tk-ui-collapsible-sidebar-radius: 1rem; }`.
