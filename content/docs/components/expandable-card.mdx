## Usage

```tsx
import {
  ExpandableCard,
  ExpandableCardBody,
  ExpandableCardContent,
  ExpandableCardDescription,
  ExpandableCardMedia,
  ExpandableCardTitle,
  ExpandableCardTrigger,
} from "@/components/transitions/expandable-card";
```

Put the same `Media`, `Title` and `Description` in both the trigger and the content. Each pair morphs into the other; `Body` only shows in the dialog.

```tsx
<ExpandableCard>
  <ExpandableCardTrigger>
    <ExpandableCardMedia>
      <img src="/aegean.jpg" alt="" />
    </ExpandableCardMedia>
    <ExpandableCardTitle>Aegean Sailing</ExpandableCardTitle>
    <ExpandableCardDescription>Greece · 5 days</ExpandableCardDescription>
  </ExpandableCardTrigger>
  <ExpandableCardContent>
    <ExpandableCardMedia className="aspect-video">
      <img src="/aegean.jpg" alt="" />
    </ExpandableCardMedia>
    <ExpandableCardTitle>Aegean Sailing</ExpandableCardTitle>
    <ExpandableCardDescription>Greece · 5 days</ExpandableCardDescription>
    <ExpandableCardBody>Hop between quiet islands…</ExpandableCardBody>
  </ExpandableCardContent>
</ExpandableCard>
```

```tsx
const BookButton = () => {
  const { setOpen } = useExpandableCard();
  return <button onClick={() => setOpen(false)}>Book trip</button>;
};
```

## API Reference

### ExpandableCard

| Prop           | Type                      | Default | Description                           |
| -------------- | ------------------------- | ------- | ------------------------------------- |
| `onOpenChange` | `(open: boolean) => void` | -       | Called when the card opens or closes. |

### ExpandableCardContent

Renders a modal `<dialog>` in `document.body`. Escape, the backdrop and the close button all fold the card back.

### useExpandableCard

| Return    | Type                      | Description                               |
| --------- | ------------------------- | ----------------------------------------- |
| `open`    | `boolean`                 | Whether the card is open.                 |
| `setOpen` | `(open: boolean) => void` | Opens or closes with the morph animation. |
