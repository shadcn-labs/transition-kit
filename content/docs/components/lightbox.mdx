## Usage

```tsx
import { Lightbox } from "@/components/transitions/lightbox";
```

```tsx
<Lightbox
  items={[
    {
      id: "dunes",
      src: "/photos/dunes.jpg",
      alt: "Dusk over the dunes",
      caption: "Dusk over the dunes",
    },
    { id: "harbour", src: "/photos/harbour.jpg", alt: "Harbour lights" },
    { id: "canyon", src: "/photos/canyon.jpg", alt: "Copper canyon" },
  ]}
/>
```

Click a photo to open it. Use the arrows, the arrow keys or a swipe to move between photos, and Escape, the close button or a click outside the photo to fold it back into the grid.

## API Reference

### Lightbox

| Prop        | Type             | Default | Description                               |
| ----------- | ---------------- | ------- | ----------------------------------------- |
| `items`     | `LightboxItem[]` | -       | The photos, in order.                     |
| `className` | `string`         | -       | Classes for the grid, e.g. `grid-cols-3`. |

### LightboxItem

| Field     | Type              | Description                              |
| --------- | ----------------- | ---------------------------------------- |
| `id`      | `string`          | Stable id, unique within the gallery.    |
| `src`     | `string`          | Image URL.                               |
| `alt`     | `string`          | Alt text, also the dialog's name.        |
| `caption` | `React.ReactNode` | Shown under the open photo.              |
| `width`   | `number`          | Intrinsic width, to avoid layout shift.  |
| `height`  | `number`          | Intrinsic height, to avoid layout shift. |
