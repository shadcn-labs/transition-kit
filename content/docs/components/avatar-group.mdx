## Usage

```tsx
import { AvatarGroup } from "@/components/transitions/avatar-group";
```

```tsx
<AvatarGroup
  aria-label="Reviewers"
  max={3}
  items={[
    { name: "Ada Lovelace", src: "/avatars/ada.jpg" },
    { name: "Grace Hopper", src: "/avatars/grace.jpg" },
    { name: "Alan Turing" },
    { name: "Katherine Johnson" },
    { name: "Margaret Hamilton" },
  ]}
/>
```

Avatars without a `src`, or whose image fails to load, show their initials. Pass `fallback` to choose the text.

## API Reference

### AvatarGroup

| Prop               | Type                          | Default    | Description                                             |
| ------------------ | ----------------------------- | ---------- | ------------------------------------------------------- |
| `items`            | `AvatarGroupItem[]`           | -          | People to show, in order.                               |
| `max`              | `number`                      | `4`        | Avatars shown while collapsed; the rest sit behind +N.  |
| `size`             | `"sm" \| "md" \| "lg"`        | `"md"`     | Avatar size.                                            |
| `expanded`         | `boolean`                     | -          | Controlled expanded state.                              |
| `defaultExpanded`  | `boolean`                     | `false`    | Initial expanded state when uncontrolled.               |
| `onExpandedChange` | `(expanded: boolean) => void` | -          | Called when the +N button expands or collapses the row. |
| `aria-label`       | `string`                      | `"People"` | Accessible name of the group.                           |

### AvatarGroupItem

| Field      | Type     | Description                                        |
| ---------- | -------- | -------------------------------------------------- |
| `name`     | `string` | The person's name, used for `alt` and the title.   |
| `src`      | `string` | Image URL.                                         |
| `fallback` | `string` | Text shown without an image. Defaults to initials. |
