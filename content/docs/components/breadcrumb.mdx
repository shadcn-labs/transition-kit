## Usage

```tsx
import { Breadcrumb } from "@/components/transitions/breadcrumb";
```

```tsx
<Breadcrumb
  items={[
    { id: "projects", label: "Projects" },
    { id: "website", label: "website" },
    { id: "src", label: "src" },
  ]}
  onNavigate={(id, index) => setPath(path.slice(0, index + 1))}
/>
```

The last item is the current page. Clicking an earlier crumb calls `onNavigate` inside a transition marked `BACK`, so the crumbs after it slide away. Mark your own forward navigation with `FORWARD` and new crumbs slide in:

```tsx
import { FORWARD } from "@/components/transitions/ui-transition";

startTransition(() => {
  addTransitionType(FORWARD);
  setPath([...path, folder]);
});
```

## API Reference

### Breadcrumb

| Prop         | Type                                  | Default        | Description                                                     |
| ------------ | ------------------------------------- | -------------- | --------------------------------------------------------------- |
| `items`      | `BreadcrumbItem[]`                    | -              | The trail, from the root to the current page.                   |
| `onNavigate` | `(id: string, index: number) => void` | -              | Called when an earlier crumb is clicked.                        |
| `maxItems`   | `number`                              | `4`            | Longer trails keep the first crumb and the last `maxItems - 1`. |
| `separator`  | `React.ReactNode`                     | Chevron        | Rendered between crumbs.                                        |
| `aria-label` | `string`                              | `"Breadcrumb"` | Accessible name of the navigation landmark.                     |

### BreadcrumbItem

| Field   | Type              | Description                         |
| ------- | ----------------- | ----------------------------------- |
| `id`    | `string`          | Stable id, unique within the trail. |
| `label` | `React.ReactNode` | Crumb text.                         |
| `icon`  | `React.ReactNode` | Rendered before the label.          |
