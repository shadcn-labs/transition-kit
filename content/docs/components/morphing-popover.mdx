## Usage

```tsx
import {
  MorphingPopover,
  MorphingPopoverClose,
  MorphingPopoverContent,
  MorphingPopoverTitle,
  MorphingPopoverTrigger,
} from "@/components/transitions/morphing-popover";
```

```tsx
<MorphingPopover>
  <MorphingPopoverTrigger>
    <MessageSquareIcon />
    Feedback
  </MorphingPopoverTrigger>
  <MorphingPopoverContent>
    <MorphingPopoverTitle>
      <MessageSquareIcon />
      Feedback
    </MorphingPopoverTitle>
    <textarea aria-label="Your feedback" />
    <MorphingPopoverClose>Cancel</MorphingPopoverClose>
  </MorphingPopoverContent>
</MorphingPopover>
```

```tsx
<MorphingPopoverContent side="top" align="end">
  …
</MorphingPopoverContent>
```

```tsx
const SendButton = () => {
  const { setOpen } = useMorphingPopover();
  return (
    <button type="submit" onClick={() => setOpen(false)}>
      Send
    </button>
  );
};
```

## API Reference

### MorphingPopover

| Prop           | Type                      | Default | Description                                        |
| -------------- | ------------------------- | ------- | -------------------------------------------------- |
| `open`         | `boolean`                 | -       | Controlled open state.                             |
| `defaultOpen`  | `boolean`                 | `false` | Initial open state when uncontrolled.              |
| `onOpenChange` | `(open: boolean) => void` | -       | Called when the open state is requested to change. |

### MorphingPopoverContent

| Prop    | Type                           | Default    | Description                                 |
| ------- | ------------------------------ | ---------- | ------------------------------------------- |
| `side`  | `"bottom" \| "top"`            | `"bottom"` | Which way the panel grows.                  |
| `align` | `"start" \| "center" \| "end"` | `"start"`  | Which trigger edge the panel lines up with. |

### useMorphingPopover

| Return    | Type                      | Description                                 |
| --------- | ------------------------- | ------------------------------------------- |
| `open`    | `boolean`                 | Whether the popover is open.                |
| `setOpen` | `(open: boolean) => void` | Opens or closes with the trigger animation. |

## Accessibility

- The trigger announces a dialog popup and its expanded state, and points at the panel with `aria-controls`. The panel is a `dialog` labelled by its title.
- Opening moves focus to the element with `data-autofocus`, else the first form field, else the panel itself.
- <kbd>Escape</kbd> closes it and returns focus to the trigger. Tabbing out of
  the panel or pressing outside it closes it too, leaving focus where you put
  it; if focus would be lost, it goes back to the trigger.
- With `prefers-reduced-motion`, nothing grows or travels; the trigger and panel crossfade briefly.
