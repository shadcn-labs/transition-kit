## Theme

Animate light and dark theme changes. Styles plug into `ThemeTransitionProvider`; components are ready-made toggles built on it. [Read more](/docs/components/theme).

## Page

Animate navigation between routes with `<PageTransition>` and `navigateWithTransition`. [Read more](/docs/components/page).

<ItemGrid group="page" />

## UI

Interactive components whose state changes glide, morph and slide with `<ViewTransition>`, built on the `tk-*` classes of the UI core. [Read more](/docs/components/ui).
