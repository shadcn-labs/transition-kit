## Usage

```tsx
<PageTransition id={pathname} transition="glitch">
  {children}
</PageTransition>
```

```tsx
navigateWithTransition(() => navigate("/"));
```

## API Reference

| Prop         | Type                  | Default                     | Description                                                                                                                                                    |
| ------------ | --------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`              | The boundary's `transition` | `"glitch"` for this style, on `<PageTransition>` for every navigation.                                                                                         |
| `duration`   | `number`              | `400`                       | Milliseconds on `<PageTransition>`. Overrides this style's `400ms` timing. Edit `var(--tk-page-duration, 400ms)` in the style's CSS to change only this style. |
| `easing`     | `string`              | `steps(6, end)`             | Easing on `<PageTransition>`. Overrides this style's easing. Edit `var(--tk-page-easing, steps(6, end))` in the style's CSS to change only this style.         |
| `direction`  | `"forward" \| "back"` | `"forward"`                 | This style looks the same in both directions.                                                                                                                  |
