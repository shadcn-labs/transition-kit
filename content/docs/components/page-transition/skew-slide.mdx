## Usage

```tsx
<PageTransition id={pathname} transition="skew-slide">
  {children}
</PageTransition>
```

```tsx
navigateWithTransition(() => navigate("/"), { direction: "back" });
```

## API Reference

| Prop         | Type                  | Default                        | Description                                                                                                                                                           |
| ------------ | --------------------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`              | The boundary's `transition`    | `"skew-slide"` for this style, on `<PageTransition>` for every navigation.                                                                                            |
| `duration`   | `number`              | `450`                          | Milliseconds on `<PageTransition>`. Overrides this style's `450ms` timing. Edit `var(--tk-page-duration, 450ms)` in the style's CSS to change only this style.        |
| `easing`     | `string`              | `cubic-bezier(0.4, 0, 0.2, 1)` | Easing on `<PageTransition>`. Overrides this style's easing. Edit `var(--tk-page-easing, cubic-bezier(0.4, 0, 0.2, 1))` in the style's CSS to change only this style. |
| `direction`  | `"forward" \| "back"` | `"forward"`                    | Pass `{ direction: "back" }` to `navigateWithTransition` to run the style in reverse.                                                                                 |
