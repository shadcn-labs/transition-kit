## Usage

```tsx
<PageTransition id={pathname} transition="blur">
  {children}
</PageTransition>
```

```tsx
navigateWithTransition(() => navigate("/"));
```

## API Reference

| Prop         | Type                  | Default                     | Description                                                                                                                                                    |
| ------------ | --------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`              | The boundary's `transition` | `"blur"` for this style, on `<PageTransition>` for every navigation.                                                                                           |
| `duration`   | `number`              | `500`                       | Milliseconds on `<PageTransition>`. Overrides this style's `500ms` timing. Edit `var(--tk-page-duration, 500ms)` in the style's CSS to change only this style. |
| `easing`     | `string`              | `ease-in-out`               | Easing on `<PageTransition>`. Overrides this style's easing. Edit `var(--tk-page-easing, ease-in-out)` in the style's CSS to change only this style.           |
| `direction`  | `"forward" \| "back"` | `"forward"`                 | This style looks the same in both directions.                                                                                                                  |
