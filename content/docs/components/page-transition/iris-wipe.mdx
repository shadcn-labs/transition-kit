## Usage

```tsx
<PageTransition id={pathname} transition="iris-wipe">
  {children}
</PageTransition>
```

```tsx
navigateWithTransition(() => navigate("/"));
```

## API Reference

| Prop         | Type                  | Default                     | Description                                                                                                                                                    |
| ------------ | --------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`              | The boundary's `transition` | `"iris-wipe"` for this style, on `<PageTransition>` for every navigation.                                                                                      |
| `duration`   | `number`              | `700`                       | Milliseconds on `<PageTransition>`. Overrides this style's `700ms` timing. Edit `var(--tk-page-duration, 700ms)` in the style's CSS to change only this style. |
| `easing`     | `string`              | `ease-in`                   | Easing on `<PageTransition>`. Overrides this style's easing. Edit `var(--tk-page-easing, ease-in)` in the style's CSS to change only this style.               |
| `direction`  | `"forward" \| "back"` | `"forward"`                 | This style looks the same in both directions.                                                                                                                  |
