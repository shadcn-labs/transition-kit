## Usage

```tsx
<PageTransition id={pathname} transition="cube">
  {children}
</PageTransition>
```

```tsx
navigateWithTransition(() => navigate("/"), { direction: "back" });
```

## API Reference

| Prop         | Type                  | Default                     | Description                                                                                                                                                    |
| ------------ | --------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`              | The boundary's `transition` | `"cube"` for this style, on `<PageTransition>` for every navigation.                                                                                           |
| `duration`   | `number`              | `700`                       | Milliseconds on `<PageTransition>`. Overrides this style's `700ms` timing. Edit `var(--tk-page-duration, 700ms)` in the style's CSS to change only this style. |
| `easing`     | `string`              | `ease-in-out`               | Easing on `<PageTransition>`. Overrides this style's easing. Edit `var(--tk-page-easing, ease-in-out)` in the style's CSS to change only this style.           |
| `direction`  | `"forward" \| "back"` | `"forward"`                 | Pass `{ direction: "back" }` to `navigateWithTransition` to run the style in reverse.                                                                          |
