## Usage

```tsx
<PageTransition id={pathname} transition="doorway">
  {children}
</PageTransition>
```

```tsx
navigateWithTransition(() => navigate("/"), { direction: "back" });
```

## API Reference

| Prop         | Type                  | Default                     | Description                                                                                                                                                    |
| ------------ | --------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`              | The boundary's `transition` | `"doorway"` for this style, on `<PageTransition>` for every navigation.                                                                                        |
| `duration`   | `number`              | `600`                       | Milliseconds on `<PageTransition>`. Overrides this style's `600ms` timing. Edit `var(--tk-page-duration, 600ms)` in the style's CSS to change only this style. |
| `easing`     | `string`              | `ease-in`                   | Easing on `<PageTransition>`. Overrides this style's easing. Edit `var(--tk-page-easing, ease-in)` in the style's CSS to change only this style.               |
| `direction`  | `"forward" \| "back"` | `"forward"`                 | Pass `{ direction: "back" }` to `navigateWithTransition` to run the style in reverse.                                                                          |
