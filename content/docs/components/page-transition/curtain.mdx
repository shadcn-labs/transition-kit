## Usage

```tsx

  {children}
</PageTransition>
```

```tsx
navigateWithTransition(() => navigate("/"));
```

## API Reference

| Prop         | Type                  | Default                          | Description                                                                                                                                                             |
| ------------ | --------------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`              | The boundary's `transition`      | `"curtain"` for this style, on `<PageTransition>` for every navigation.                                                                                                 |
| `duration`   | `number`              | `600`                            | Milliseconds on `<PageTransition>`. Overrides this style's `600ms` timing. Edit `var(--tk-page-duration, 600ms)` in the style's CSS to change only this style.          |
| `easing`     | `string`              | `cubic-bezier(0.65, 0, 0.35, 1)` | Easing on `<PageTransition>`. Overrides this style's easing. Edit `var(--tk-page-easing, cubic-bezier(0.65, 0, 0.35, 1))` in the style's CSS to change only this style. |
| `direction`  | `"forward" \| "back"` | `"forward"`                      | This style looks the same in both directions.                                                                                                                           |
