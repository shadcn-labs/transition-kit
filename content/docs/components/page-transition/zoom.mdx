```tsx

  {children}
</PageTransition>
```

## API Reference

| Prop         | Type                  | Default                        | Description                                                                                                                                                           |
| ------------ | --------------------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`              | The boundary's `transition`    | `"zoom"` for this style, on `<PageTransition>` for every navigation.                                                                                                  |
| `duration`   | `number`              | `400`                          | Milliseconds on `<PageTransition>`. Overrides this style's `400ms` timing. Edit `var(--tk-page-duration, 400ms)` in the style's CSS to change only this style.        |
| `easing`     | `string`              | `cubic-bezier(0.4, 0, 0.2, 1)` | Easing on `<PageTransition>`. Overrides this style's easing. Edit `var(--tk-page-easing, cubic-bezier(0.4, 0, 0.2, 1))` in the style's CSS to change only this style. |
| `direction`  | `"forward" \| "back"` | `"forward"`                    | Pass `{ direction: "back" }` to `navigateWithTransition` to run the style in reverse.                                                                                 |
