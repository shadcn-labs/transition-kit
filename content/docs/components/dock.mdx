## Usage

```tsx
import { Dock, DockItem } from "@/components/transitions/dock";
```

```tsx
<Dock defaultValue="home" aria-label="App sections">
  <DockItem value="home" icon={<Home />} label="Home" />
  <DockItem value="search" icon={<Search />} label="Search" />
  <DockItem value="inbox" icon={<Inbox />} label="Inbox" />
</Dock>
```

The dock is a toolbar: Tab moves focus into it, and the arrow keys, Home and End move between items.

## API Reference

### Dock

| Prop            | Type                      | Default | Description                                   |
| --------------- | ------------------------- | ------- | --------------------------------------------- |
| `value`         | `string`                  | -       | Controlled active item.                       |
| `defaultValue`  | `string`                  | `""`    | Initial active item when uncontrolled.        |
| `onValueChange` | `(value: string) => void` | -       | Called with the next value when it is chosen. |
| `aria-label`    | `string`                  | -       | Accessible name of the toolbar.               |

### DockItem

| Prop       | Type              | Default | Description                                               |
| ---------- | ----------------- | ------- | --------------------------------------------------------- |
| `value`    | `string`          | -       | Value this item activates.                                |
| `icon`     | `React.ReactNode` | -       | The item's icon.                                          |
| `label`    | `string`          | -       | Shown beside the icon while active, and as the item name. |
| `disabled` | `boolean`         | `false` | Disables this item.                                       |
