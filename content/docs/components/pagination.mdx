## Usage

```tsx
import { Pagination } from "@/components/transitions/pagination";
```

```tsx
<Pagination total={12} defaultPage={1} />
```

The change runs inside `startTransition` with a `tk-forward` or `tk-back` transition type, so content keyed by the page can slide the same way:

```tsx
import { BACK, FORWARD, tk } from "@/components/transitions/ui-transition";

const slide = {
  [BACK]: tk("tk-slide", "tk-back"),
  [FORWARD]: tk("tk-slide", "tk-forward"),
  default: "none",
};

<ViewTransition key={page} default="none" enter={slide} exit={slide}>
  <Results page={page} />
</ViewTransition>
<Pagination total={12} page={page} onPageChange={setPage} />
```

## API Reference

### Pagination

| Prop           | Type                     | Default        | Description                                    |
| -------------- | ------------------------ | -------------- | ---------------------------------------------- |
| `total`        | `number`                 | -              | Number of pages.                               |
| `page`         | `number`                 | -              | Controlled current page, starting at 1.        |
| `defaultPage`  | `number`                 | `1`            | Initial page when uncontrolled.                |
| `onPageChange` | `(page: number) => void` | -              | Called with the next page when it is selected. |
| `siblings`     | `number`                 | `1`            | Pages shown on each side of the current one.   |
| `boundaries`   | `number`                 | `1`            | Pages always shown at the start and end.       |
| `size`         | `"sm" \| "md"`           | `"md"`         | Item size.                                     |
| `disabled`     | `boolean`                | `false`        | Disables every control.                        |
| `aria-label`   | `string`                 | `"Pagination"` | Accessible name of the navigation landmark.    |
