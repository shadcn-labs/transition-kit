## Usage

```tsx
<ThemeTransitionProvider transition="venetian-blinds">
  {children}
</ThemeTransitionProvider>
```

```tsx
const { toggleTheme } = useThemeTransition();

<button
  type="button"
  onClick={(event) =>
    toggleTheme({ transition: "venetian-blinds", origin: event })
  }
>
  Toggle theme
</button>;
```

## API Reference

| Prop         | Type                                              | Default                     | Description                                                                                                                                               |
| ------------ | ------------------------------------------------- | --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`                                          | The provider's `transition` | `"venetian-blinds"` for this style: on the provider for every change, or per change with `setTheme` / `toggleTheme`.                                      |
| `duration`   | `number`                                          | `700`                       | Milliseconds on the provider. Overrides this style's `700ms` timing. Edit `var(--tk-theme-duration, 700ms)` in the style's CSS to change only this style. |
| `easing`     | `string`                                          | `ease-in-out`               | Easing on the provider. Overrides this style's easing. Edit `var(--tk-theme-easing, ease-in-out)` in the style's CSS to change only this style.           |
| `origin`     | `{ clientX: number; clientY: number } \| Element` | -                           | This style is anchored to the viewport and ignores `origin`.                                                                                              |
