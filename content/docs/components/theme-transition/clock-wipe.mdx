## Usage

```tsx
<ThemeTransitionProvider transition="clock-wipe">
  {children}
</ThemeTransitionProvider>
```

```tsx
const { toggleTheme } = useThemeTransition();

<button
  type="button"
  onClick={(event) => toggleTheme({ transition: "clock-wipe", origin: event })}
>
  Toggle theme
</button>;
```

## API Reference

| Prop         | Type                                              | Default                     | Description                                                                                                                                                 |
| ------------ | ------------------------------------------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`                                          | The provider's `transition` | `"clock-wipe"` for this style: on the provider for every change, or per change with `setTheme` / `toggleTheme`.                                             |
| `duration`   | `number`                                          | `1100`                      | Milliseconds on the provider. Overrides this style's `1100ms` timing. Edit `var(--tk-theme-duration, 1100ms)` in the style's CSS to change only this style. |
| `easing`     | `string`                                          | `linear`                    | Easing on the provider. Overrides this style's easing. Edit `var(--tk-theme-easing, linear)` in the style's CSS to change only this style.                  |
| `origin`     | `{ clientX: number; clientY: number } \| Element` | -                           | This style is anchored to the viewport and ignores `origin`.                                                                                                |
