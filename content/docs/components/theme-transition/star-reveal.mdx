## Usage

```tsx
<ThemeTransitionProvider transition="star-reveal">
  {children}
</ThemeTransitionProvider>
```

```tsx
const { toggleTheme } = useThemeTransition();

<button
  type="button"
  onClick={(event) => toggleTheme({ transition: "star-reveal", origin: event })}
>
  Toggle theme
</button>;
```

## API Reference

| Prop         | Type                                              | Default                     | Description                                                                                                                                                 |
| ------------ | ------------------------------------------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`                                          | The provider's `transition` | `"star-reveal"` for this style: on the provider for every change, or per change with `setTheme` / `toggleTheme`.                                            |
| `duration`   | `number`                                          | `1000`                      | Milliseconds on the provider. Overrides this style's `1000ms` timing. Edit `var(--tk-theme-duration, 1000ms)` in the style's CSS to change only this style. |
| `easing`     | `string`                                          | `ease-in`                   | Easing on the provider. Overrides this style's easing. Edit `var(--tk-theme-easing, ease-in)` in the style's CSS to change only this style.                 |
| `origin`     | `{ clientX: number; clientY: number } \| Element` | The viewport centre         | Pass the click event to start at the pointer, or an element to start at its centre.                                                                         |
