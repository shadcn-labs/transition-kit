## Usage

```tsx
<ThemeTransitionProvider transition="circle-blur">
  {children}
</ThemeTransitionProvider>
```

```tsx
const { toggleTheme } = useThemeTransition();

<button
  type="button"
  onClick={(event) => toggleTheme({ transition: "circle-blur", origin: event })}
>
  Toggle theme
</button>;
```

## API Reference

| Prop         | Type                                              | Default                         | Description                                                                                                                                                       |
| ------------ | ------------------------------------------------- | ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`                                          | The provider's `transition`     | `"circle-blur"` for this style: on the provider for every change, or per change with `setTheme` / `toggleTheme`.                                                  |
| `duration`   | `number`                                          | `1000`                          | Milliseconds on the provider. Overrides this style's `1000ms` timing. Edit `var(--tk-theme-duration, 1000ms)` in the style's CSS to change only this style.       |
| `easing`     | `string`                                          | `cubic-bezier(0.16, 1, 0.3, 1)` | Easing on the provider. Overrides this style's easing. Edit `var(--tk-theme-easing, cubic-bezier(0.16, 1, 0.3, 1))` in the style's CSS to change only this style. |
| `origin`     | `{ clientX: number; clientY: number } \| Element` | The viewport centre             | Pass the click event to start at the pointer, or an element to start at its centre.                                                                               |
