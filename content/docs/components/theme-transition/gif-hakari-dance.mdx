## Usage

```tsx
<ThemeTransitionProvider transition="gif-hakari-dance">
  {children}
</ThemeTransitionProvider>
```

```tsx
const { toggleTheme } = useThemeTransition();

<button
  type="button"
  onClick={(event) =>
    toggleTheme({ transition: "gif-hakari-dance", origin: event })
  }
>
  Toggle theme
</button>;
```

## API Reference

| Prop         | Type                                              | Default                         | Description                                                                                                                                                       |
| ------------ | ------------------------------------------------- | ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `transition` | `string`                                          | The provider's `transition`     | `"gif-hakari-dance"` for this style: on the provider for every change, or per change with `setTheme` / `toggleTheme`.                                             |
| `duration`   | `number`                                          | `1500`                          | Milliseconds on the provider. Overrides this style's `1500ms` timing. Edit `var(--tk-theme-duration, 1500ms)` in the style's CSS to change only this style.       |
| `easing`     | `string`                                          | `cubic-bezier(0.16, 1, 0.3, 1)` | Easing on the provider. Overrides this style's easing. Edit `var(--tk-theme-easing, cubic-bezier(0.16, 1, 0.3, 1))` in the style's CSS to change only this style. |
| `origin`     | `{ clientX: number; clientY: number } \| Element` | The viewport centre             | Pass the click event to start at the pointer, or an element to start at its centre.                                                                               |

## Notes

The mask is a GIF loaded from Tenor:

```txt
https://media.tenor.com/uRlxzRNgp2MAAAAi/anime-girl.gif
```

Until the browser has downloaded it, the mask is empty and the theme switches when the transition ends. Preload it so the first transition plays, or download it and serve it from your own domain:

```tsx
<link
  rel="preload"
  as="image"
  href="https://media.tenor.com/uRlxzRNgp2MAAAAi/anime-girl.gif"
/>
```

If you swap in another image, keep the reveal centred by updating the aspect ratio (height ÷ width) used in the `mask-position` calculations.
