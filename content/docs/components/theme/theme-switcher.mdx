## Usage

Render it anywhere inside `ThemeTransitionProvider`.

```tsx
import { ThemeSwitcher } from "@/components/transitions/theme-switcher";
```

```tsx
<ThemeSwitcher />
<ThemeSwitcher transition="polygon-reveal" />
```

## API Reference

### ThemeSwitcher

| Prop         | Type                    | Default                     |
| ------------ | ----------------------- | --------------------------- |
| `transition` | `string`                | The provider's `transition` |
| `...props`   | `ComponentProps<"div">` | -                           |

`transition` is a style slug such as `"circle-reveal"`; install the style first. Other props are spread onto the radio group.

## Accessibility

- A `role="radiogroup"` labelled "Theme" with one `role="radio"` button per option and `aria-checked` on the active one.
- Roving focus: <kbd>Tab</kbd> lands on the checked option. <kbd>←</kbd> <kbd>↑</kbd> and <kbd>→</kbd> <kbd>↓</kbd> move to the previous and next option and select it, wrapping at the ends; <kbd>Home</kbd> and <kbd>End</kbd> jump to the first and last option.
- The stored theme is unknown on the server, so no option is checked until hydration; the first option is focusable meanwhile.
