A 4 × 4 checkerboard grows from the origin, and a trailing circle fills the remaining tiles so the reveal always ends on the full new theme. It starts at the transition origin: the pointer when you pass the click event, the centre of a control activated from the keyboard, or the centre of the viewport when you pass no `origin`.

## Usage

Make it the default style of the provider:

```tsx
<ThemeTransitionProvider transition="checkerboard-reveal">
  {children}
</ThemeTransitionProvider>
```

Or use it for a single change:

```tsx
const { toggleTheme } = useThemeTransition();

<button
  type="button"
  onClick={(event) =>
    toggleTheme({ transition: "checkerboard-reveal", origin: event })
  }
>
  Toggle theme
</button>;
```

## Customization

The style runs for `1000ms` with `ease-in-out` easing. `duration` (in milliseconds) and `easing` on the provider override every style:

```tsx
<ThemeTransitionProvider
  transition="checkerboard-reveal"
  duration={1500}
  easing="ease-out"
>
  {children}
</ThemeTransitionProvider>
```

To change only this style, edit the fallbacks in its CSS: `var(--tk-theme-duration, 1000ms)` and `var(--tk-theme-easing, ease-in-out)`.

Pass the click event as `origin` to start at the pointer, or an element to start at its centre:

```tsx
toggleTheme({ origin: event });
setTheme("dark", { origin: buttonElement });
```
