## Usage

Render it anywhere inside `ThemeTransitionProvider`.

```tsx
import { ThemeToggleSwitch } from "@/components/transitions/theme-toggle-switch";
```

```tsx
<ThemeToggleSwitch />
<ThemeToggleSwitch transition="star-reveal" />
```

## API Reference

### ThemeToggleSwitch

| Prop         | Type                       | Default                     |
| ------------ | -------------------------- | --------------------------- |
| `transition` | `string`                   | The provider's `transition` |
| `...props`   | `ComponentProps<"button">` | -                           |

`transition` is a style slug such as `"circle-reveal"`; install the style first. Any other prop is spread onto the `<button>`; calling `event.preventDefault()` in your `onClick` skips the theme change.

## Accessibility

- A `<button role="switch">` labelled "Dark mode", with `aria-checked` set when the dark theme is active. Pass `aria-label` to change the label.
- Toggles with <kbd>Space</kbd> or <kbd>Enter</kbd>; keyboard changes start the transition at the switch.
- The thumb follows the `dark` class on `<html>`, so it is in the right place before hydration. `aria-checked` stays `false` until the theme is known.
