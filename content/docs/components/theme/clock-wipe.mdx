A hand sweeps clockwise around the centre of the viewport, starting at twelve o'clock. It is anchored to the viewport, so it ignores `origin` and always covers exactly what is on screen, even when the page is scrolled.

## Usage

Make it the default style of the provider:

```tsx
<ThemeTransitionProvider transition="clock-wipe">
  {children}
</ThemeTransitionProvider>
```

Or use it for a single change:

```tsx
const { toggleTheme } = useThemeTransition();

<button
  type="button"
  onClick={(event) => toggleTheme({ transition: "clock-wipe", origin: event })}
>
  Toggle theme
</button>;
```

## Customization

The style runs for `1100ms` with `linear` easing. `duration` (in milliseconds) and `easing` on the provider override every style:

```tsx
<ThemeTransitionProvider
  transition="clock-wipe"
  duration={1500}
  easing="ease-out"
>
  {children}
</ThemeTransitionProvider>
```

To change only this style, edit the fallbacks in its CSS: `var(--tk-theme-duration, 1100ms)` and `var(--tk-theme-easing, linear)`.
