## Usage

Render it anywhere inside `ThemeTransitionProvider`.

```tsx
import { ThemeToggleButton } from "@/components/transitions/theme-toggle-button";
```

```tsx
<ThemeToggleButton />
<ThemeToggleButton transition="circle-blur" />
```

## API Reference

### ThemeToggleButton

| Prop         | Type                       | Default                     |
| ------------ | -------------------------- | --------------------------- |
| `transition` | `string`                   | The provider's `transition` |
| `...props`   | `ComponentProps<"button">` | -                           |

`transition` is a style slug such as `"circle-reveal"`; install the style first. Any other prop is spread onto the `<button>`; calling `event.preventDefault()` in your `onClick` skips the theme change.

## Accessibility

- A native `<button type="button">`, reachable with <kbd>Tab</kbd> and activated with <kbd>Enter</kbd> or <kbd>Space</kbd>.
- `aria-label` describes the action: "Switch to dark theme" or "Switch to light theme". Until the theme is known after hydration it reads "Toggle theme".
- The icons are decorative (`aria-hidden`) and follow the `dark` class on `<html>`, so they are correct before hydration.
