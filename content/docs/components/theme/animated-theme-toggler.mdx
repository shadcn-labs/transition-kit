An icon button whose sun shrinks its rays and grows into a crescent moon, and back. The morph is driven by CSS transitions on the `dark` class, which the provider flips inside the view transition, so it plays inside the new theme as the style reveals it.

## Usage

Render it anywhere inside `ThemeTransitionProvider`.

```tsx
import { AnimatedThemeToggler } from "@/components/transitions/animated-theme-toggler";
```

```tsx
<AnimatedThemeToggler />
<AnimatedThemeToggler transition="circle-reveal" />
```

## API Reference

### AnimatedThemeToggler

| Prop         | Type                       | Default                     |
| ------------ | -------------------------- | --------------------------- |
| `transition` | `string`                   | The provider's `transition` |
| `...props`   | `ComponentProps<"button">` | -                           |

`transition` is a style slug such as `"circle-reveal"`; install the style first. Any other prop is spread onto the `<button>`; calling `event.preventDefault()` in your `onClick` skips the theme change.

## Accessibility

- A native `<button type="button">` whose `aria-label` describes the action: "Switch to dark theme" or "Switch to light theme" ("Toggle theme" until hydration).
- The icon is decorative (`aria-hidden`).
- The morph is disabled when the user prefers reduced motion; the core already skips the theme transition in that case.
