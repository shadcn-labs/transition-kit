The old page turns away around its left edge and the new one turns in around its right edge, like flipping a card. Backward navigations mirror the hinges.

## Usage

```tsx
<PageTransition id={pathname} transition="flip">
  {children}
</PageTransition>
```

Mark backward navigations with `direction: "back"` and the style runs the other way:

```tsx
navigateWithTransition(() => navigate("/"), { direction: "back" });
```

## Customization

The style runs for `600ms` with `ease-in-out` easing. `duration` (in milliseconds) and `easing` on `<PageTransition>` override it:

```tsx
<PageTransition
  id={pathname}
  transition="flip"
  duration={1200}
  easing="ease-out"
>
  {children}
</PageTransition>
```

To change only this style, edit the fallbacks in its CSS: `var(--tk-page-duration, 600ms)` and `var(--tk-page-easing, ease-in-out)`.

The hinges sit on the edges of the page's visible part, vertically centred on it, so long scrolled pages turn around what the user sees.

The 3D depth comes from `perspective: 1200px` on `::view-transition-image-pair(.tk-page-flip)`; lower it for a stronger effect.
