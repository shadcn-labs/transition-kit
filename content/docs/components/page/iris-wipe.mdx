## Usage

```tsx
<PageTransition id={pathname} transition="iris-wipe">
  {children}
</PageTransition>
```

Navigations that run in a React Transition animate: router links, or any update wrapped in `navigateWithTransition`. The style looks the same in both directions.

## Customization

The whole transition runs for `700ms`: the iris closes for the first half with `ease-in` and opens for the second half with `ease-out`. `duration` and `easing` on `<PageTransition>` override it; `duration` is still split in half and `easing` applies to both halves:

```tsx
<PageTransition
  id={pathname}
  transition="iris-wipe"
  duration={1000}
  easing="ease-out"
>
  {children}
</PageTransition>
```

To change only this style, edit the fallbacks in its CSS: `var(--tk-page-duration, 700ms)` and `var(--tk-page-easing, ease-in)` (and `ease-out` for the new page).

The iris is centred on the page's visible part and sized to cover it.
