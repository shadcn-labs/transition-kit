## Usage

```tsx
<PageTransition id={pathname} transition="rotate">
  {children}
</PageTransition>
```

Mark backward navigations with `direction: "back"` and the style runs the other way:

```tsx
navigateWithTransition(() => navigate("/"), { direction: "back" });
```

## Customization

The style runs for `500ms` with `cubic-bezier(0.4, 0, 0.2, 1)` easing. `duration` (in milliseconds) and `easing` on `<PageTransition>` override it:

```tsx
<PageTransition
  id={pathname}
  transition="rotate"
  duration={1000}
  easing="ease-out"
>
  {children}
</PageTransition>
```

To change only this style, edit the fallbacks in its CSS: `var(--tk-page-duration, 500ms)` and `var(--tk-page-easing, cubic-bezier(0.4, 0, 0.2, 1))`.

It pivots around the centre of the page's visible part, so long scrolled pages and pages inside a smaller frame both animate around what the user sees.
