## Usage

```tsx
<PageTransition id={pathname} transition="fade">
  {children}
</PageTransition>
```

Navigations that run in a React Transition animate: router links, or any update wrapped in `navigateWithTransition`. The style looks the same in both directions.

## Customization

The style runs for `300ms` with `ease-in-out` easing. `duration` (in milliseconds) and `easing` on `<PageTransition>` override it:

```tsx
<PageTransition
  id={pathname}
  transition="fade"
  duration={600}
  easing="ease-out"
>
  {children}
</PageTransition>
```

To change only this style, edit the fallbacks in its CSS: `var(--tk-page-duration, 300ms)` and `var(--tk-page-easing, ease-in-out)`.
