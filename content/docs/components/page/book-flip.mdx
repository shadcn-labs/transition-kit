## Usage

```tsx
<PageTransition id={pathname} transition="book-flip">
  {children}
</PageTransition>
```

Mark backward navigations with `direction: "back"` and the style runs the other way:

```tsx
navigateWithTransition(() => navigate("/"), { direction: "back" });
```

## Customization

The style runs for `700ms` with `ease-in-out` easing. `duration` (in milliseconds) and `easing` on `<PageTransition>` override it:

```tsx
<PageTransition
  id={pathname}
  transition="book-flip"
  duration={1400}
  easing="ease-out"
>
  {children}
</PageTransition>
```

To change only this style, edit the fallbacks in its CSS: `var(--tk-page-duration, 700ms)` and `var(--tk-page-easing, ease-in-out)`.

It pivots around the centre of the page's visible part, so long scrolled pages and pages inside a smaller frame both animate around what the user sees.

The 3D depth comes from `perspective: 1600px` on `::view-transition-image-pair(.tk-page-book-flip)`; lower it for a stronger effect.
