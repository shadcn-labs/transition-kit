## Usage

```tsx
<PageTransition id={pathname} transition="roll">
  {children}
</PageTransition>
```

Mark backward navigations with `direction: "back"` and the style runs the other way:

```tsx
navigateWithTransition(() => navigate("/"), { direction: "back" });
```

## Customization

The style runs for `550ms` with `cubic-bezier(0.4, 0, 0.2, 1)` easing. `duration` (in milliseconds) and `easing` on `<PageTransition>` override it:

```tsx
<PageTransition
  id={pathname}
  transition="roll"
  duration={1100}
  easing="ease-out"
>
  {children}
</PageTransition>
```

To change only this style, edit the fallbacks in its CSS: `var(--tk-page-duration, 550ms)` and `var(--tk-page-easing, cubic-bezier(0.4, 0, 0.2, 1))`.

It rolls towards the top of the page's visible part, so long scrolled pages roll up to the top of the screen, not the top of the document.
