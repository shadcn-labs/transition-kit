## Usage

```tsx
<PageTransition id={pathname} transition="page-curl">
  {children}
</PageTransition>
```

Mark backward navigations with `direction: "back"` and the style runs the other way:

```tsx
navigateWithTransition(() => navigate("/"), { direction: "back" });
```

## Customization

The style runs for `650ms`; the old page uses `ease-in` and the new one `ease-out`. `duration` (in milliseconds) and `easing` on `<PageTransition>` override it for both pages:

```tsx
<PageTransition
  id={pathname}
  transition="page-curl"
  duration={1300}
  easing="ease-out"
>
  {children}
</PageTransition>
```

To change only this style, edit the fallbacks in its CSS: `var(--tk-page-duration, 650ms)` and `var(--tk-page-easing, ease-in)` (and `ease-out` for the new page).

The curl starts at the bottom corner of the page's visible part, so long scrolled pages curl from the corner of the screen.

The 3D depth comes from `perspective: 1400px` on `::view-transition-image-pair(.tk-page-page-curl)`; lower it for a stronger effect.

The old page is drawn on top of the new one with `::view-transition-group(.tk-page-page-curl.tk-page-exit) { z-index: 1; }`.
