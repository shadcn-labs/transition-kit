## Usage

```tsx
<PageTransition id={pathname} transition="glitch">
  {children}
</PageTransition>
```

Navigations that run in a React Transition animate: router links, or any update wrapped in `navigateWithTransition`. The style looks the same in both directions.

## Customization

The style runs for `400ms` with `steps(6, end)` easing. `duration` (in milliseconds) and `easing` on `<PageTransition>` override it:

```tsx
<PageTransition
  id={pathname}
  transition="glitch"
  duration={800}
  easing="ease-out"
>
  {children}
</PageTransition>
```

To change only this style, edit the fallbacks in its CSS: `var(--tk-page-duration, 400ms)` and `var(--tk-page-easing, steps(6, end))`.
