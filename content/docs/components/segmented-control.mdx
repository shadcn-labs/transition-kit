## Usage

```tsx
import {
  SegmentedControl,
  SegmentedControlItem,
} from "@/components/transitions/segmented-control";
```

```tsx
<SegmentedControl defaultValue="week" name="view" aria-label="Calendar view">
  <SegmentedControlItem value="day">Day</SegmentedControlItem>
  <SegmentedControlItem value="week">Week</SegmentedControlItem>
  <SegmentedControlItem value="month">Month</SegmentedControlItem>
</SegmentedControl>
```

```tsx
<SegmentedControl defaultValue="left" size="sm" aria-label="Text alignment">
  <SegmentedControlItem
    value="left"
    icon={<AlignLeft />}
    aria-label="Align left"
  />
  <SegmentedControlItem
    value="center"
    icon={<AlignCenter />}
    aria-label="Align center"
  />
  <SegmentedControlItem
    value="right"
    icon={<AlignRight />}
    aria-label="Align right"
  />
</SegmentedControl>
```

## API Reference

### SegmentedControl

| Prop            | Type                      | Default | Description                                                            |
| --------------- | ------------------------- | ------- | ---------------------------------------------------------------------- |
| `value`         | `string`                  | -       | Controlled selected value.                                             |
| `defaultValue`  | `string`                  | `""`    | Initial selected value when uncontrolled.                              |
| `onValueChange` | `(value: string) => void` | -       | Called with the next value when it is selected.                        |
| `name`          | `string`                  | -       | Submits the selected value with this field name in a surrounding form. |
| `form`          | `string`                  | -       | Associates the hidden input with a form elsewhere in the document.     |
| `size`          | `"sm" \| "md" \| "lg"`    | `"md"`  | Control size.                                                          |
| `disabled`      | `boolean`                 | `false` | Disables the whole control.                                            |

### SegmentedControlItem

| Prop       | Type              | Default | Description                         |
| ---------- | ----------------- | ------- | ----------------------------------- |
| `value`    | `string`          | -       | Option value selected by this item. |
| `icon`     | `React.ReactNode` | -       | Content rendered before the label.  |
| `disabled` | `boolean`         | `false` | Disables this item.                 |

## Accessibility

- Implements the WAI-ARIA radio group pattern: a `radiogroup` of `radio` buttons with `aria-checked`. Label the group with `aria-label` or `aria-labelledby`.
- Only one item is in the tab order: the checked one, or the first enabled item when nothing is checked.
- <kbd>←</kbd> / <kbd>→</kbd> (and <kbd>↑</kbd> / <kbd>↓</kbd>) move to the
  previous or next option and select it, wrapping at the ends and skipping
  disabled items. <kbd>Home</kbd> / <kbd>End</kbd> jump to the first and last
  option. Arrow keys follow the reading direction in right-to-left layouts.
- With `prefers-reduced-motion`, the thumb doesn't travel; the change is a short crossfade.
