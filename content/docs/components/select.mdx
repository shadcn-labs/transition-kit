## Usage

```tsx
import { Select } from "@/components/transitions/select";
```

```tsx
<Select
  aria-label="Region"
  name="region"
  placeholder="Choose a region"
  options={[
    { label: "Frankfurt", value: "fra" },
    { label: "London", value: "lhr" },
    { label: "Singapore", value: "sin" },
  ]}
/>
```

The list opens over the trigger. Use the arrow keys, Home, End or type a few letters to move, Enter or Space to choose, and Escape to close.

## API Reference

### Select

| Prop              | Type                      | Default     | Description                                                            |
| ----------------- | ------------------------- | ----------- | ---------------------------------------------------------------------- |
| `options`         | `SelectOption[]`          | -           | The choices, in order.                                                 |
| `value`           | `string`                  | -           | Controlled selected value.                                             |
| `defaultValue`    | `string`                  | -           | Initial selected value when uncontrolled.                              |
| `onValueChange`   | `(value: string) => void` | -           | Called with the next value when it is chosen.                          |
| `placeholder`     | `string`                  | `"Select…"` | Shown while nothing is selected.                                       |
| `name`            | `string`                  | -           | Submits the selected value with this field name in a surrounding form. |
| `form`            | `string`                  | -           | Associates the hidden input with a form elsewhere in the document.     |
| `disabled`        | `boolean`                 | `false`     | Disables the select.                                                   |
| `aria-label`      | `string`                  | -           | Accessible name, when there is no visible label.                       |
| `aria-labelledby` | `string`                  | -           | Id of a visible label.                                                 |

### SelectOption

| Field      | Type              | Description                  |
| ---------- | ----------------- | ---------------------------- |
| `value`    | `string`          | Value submitted and stored.  |
| `label`    | `string`          | Text shown and typed to.     |
| `icon`     | `React.ReactNode` | Rendered before the label.   |
| `disabled` | `boolean`         | Makes the option unpickable. |
