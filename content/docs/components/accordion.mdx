## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/transitions/accordion";
```

```tsx
<Accordion type="single" collapsible defaultValue="shipping">
  <AccordionItem value="shipping">
    <AccordionTrigger>How long does shipping take?</AccordionTrigger>
    <AccordionContent>Orders ship within two business days.</AccordionContent>
  </AccordionItem>
  <AccordionItem value="returns">
    <AccordionTrigger>Can I return an order?</AccordionTrigger>
    <AccordionContent>Yes, within 30 days of delivery.</AccordionContent>
  </AccordionItem>
</Accordion>
```

## API Reference

### Accordion

| Prop            | Type                                                    | Default | Description                                       |
| --------------- | ------------------------------------------------------- | ------- | ------------------------------------------------- |
| `type`          | `"single" \| "multiple"`                                | -       | Single-open or multi-open behavior.               |
| `value`         | `string` (single) / `string[]` (multiple)               | -       | Controlled open item(s).                          |
| `defaultValue`  | `string` (single) / `string[]` (multiple)               | -       | Initial open item(s) when uncontrolled.           |
| `onValueChange` | `(value: string) => void` / `(value: string[]) => void` | -       | Called with the new open value when items toggle. |
| `collapsible`   | `boolean` (single only)                                 | `false` | Lets the open item close, leaving none open.      |

### AccordionItem

| Prop       | Type      | Default | Description                     |
| ---------- | --------- | ------- | ------------------------------- |
| `value`    | `string`  | -       | Unique identifier for the item. |
| `disabled` | `boolean` | `false` | Disables the item's trigger.    |
