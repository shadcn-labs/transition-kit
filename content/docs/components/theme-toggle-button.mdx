
## API Reference

### ThemeToggleButton

| Prop         | Type                       | Default                     | Description                                                                                       |
| ------------ | -------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------- |
| `transition` | `string`                   | The provider's `transition` | Style slug such as `"circle-reveal"`. Install the style first.                                    |
| `...props`   | `ComponentProps<"button">` | -                           | Spread onto the `<button>`. Calling `event.preventDefault()` in `onClick` skips the theme change. |
